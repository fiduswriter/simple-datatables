Search hidden columns

Hidden columns are not searched by default. Adding data-search-hidden="true" to a th (or setting searchHidden: true globally or per column) includes the content of the hidden column in search results, without making it visible. Try searching for "Clacton" or "Norwich" — the rows match even though the City column stays hidden.
