Grouped headings

A thead may contain multiple rows that use colspan and rowspan to group columns. The cells of the last heading row define the table's columns — here Name, City and Country — including headings that span several rows. Column settings such as data-type are read from the heading cell covering the column in that last row. The table itself is rendered with a single heading row. Try sorting all three columns.
